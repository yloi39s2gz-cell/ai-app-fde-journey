## 3. 为什么是 P3（而且是最极端的一个）

| 门槛 | 说明 |
| --- | --- |
| **研究背景** | 世界模型目前处于研究阶段，岗位多为研究员/资深算法，普遍要求博士或顶会论文 |
| **算力** | 训练视频生成/世界模型需要大规模 GPU 集群 |
| **跨学科** | 需要同时懂：生成模型（Diffusion/自回归）、3D 表示（NeRF/3DGS）、物理仿真、RL |
| **岗位数量** | 扩招 644% 听起来猛，但**基数极小**（可能从 5 个涨到 37 个）——这是"高增长率低绝对量"的典型 |

> **判断关键字**：**基数**。+644% 只有在你知道分母的情况下才有意义。
> 一个 10 人的岗位池涨 7 倍是 70 人；AI 应用开发岗涨 1.2 倍是几千人。**你要去的是绝对量大的地方。**

## 1. 一句话画像

**在客户签单之前，把"我们能做什么"讲成"你的问题能怎么解决"，并给出可落地的方案与报价。**
FDE 是签单**之后**进现场交付；解决方案/售前是签单**之前**做方案。

```
解决方案/售前  ──签单──►  FDE  ──交付──►  客户成功
（讲清楚能干什么）      （真的做出来）        （用起来）
```

## 5. 判断

**AI 解决方案 / 售前 = P2。**

**优点**：
- 是 FDE 的"降级入口"——如果你想走 FDE 路线但工程经验不够，可以先做售前/解决方案，2 年后转 FDE
- 出差压力比 FDE 小
- 技术门槛低，你的技术深度绰绰有余

**缺点**：
- **销售属性重**，如果客户不签单，压力比技术岗大
- 薪资天花板低于 FDE
- 苏州/南京本轮的证据不足（下一轮核）

**建议**：**不作为主攻，但关注两条信息**：
1. 下一轮核苏州/南京有没有"AI 解决方案 / 售前"的真实 JD，门槛多少
2. 如果你在窗口三发现"出差不能接受"，那么本岗位可作为 FDE 的替代方案

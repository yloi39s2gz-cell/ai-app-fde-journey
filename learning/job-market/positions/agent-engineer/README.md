## 4. 你的匹配度：**本清单里最高**

```
要求 10 项：
✅ 已达标 3 项（Agent 循环 / trace / 注入防御）
🟡 有基础 3 项（工具定义 / 工具设计 / 评测）
❌ 缺失 4 项（多 Agent / 状态持久化 / 框架 / 服务化）
```

对比 [AI 应用工程师](../ai-application-engineer/README.md)（3 项全缺硬缺口：服务化/容器/云），
**Agent 开发岗缺的 4 项里有 3 项（原生 tools / 多 Agent / 状态持久化）都能在窗口一的 LangGraph 周（D8–D14）里一次补齐。**

> **换句话说：窗口一结束时，你同时具备了 AI 应用工程师和 Agent 开发工程师两个岗位的投递条件。**

## 6. 结论

**Agent 开发工程师 = P1，且是"性价比最高"的一个。**
理由：
1. 招聘量最大（断层第一）
2. 你的核心资产直接对口（不用重学）
3. 缺口的工作量已被窗口一吸收（LangGraph 周本来就要做）

**唯一提醒**：不要因为它"匹配度高"就把作品做成一个纯 Agent demo。
市场要的是"**Agent 解决了什么业务问题**"——所以工具要接真实系统（工单/知识库），不是 calculator。
（这一点和 [AI 应用工程师](../ai-application-engineer/README.md) 的要求完全一致，可以共用同一个作品。）

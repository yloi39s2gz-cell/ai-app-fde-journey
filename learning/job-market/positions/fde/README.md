## 1. 一句话画像

**把大模型塞进客户已有的、又脏又乱的系统里，并且让它真的产生业务结果。**
不是研发模型，不是写 PPT，是**驻场 + 交付**。

JD 里的原话最能说明它是什么：
- Deloitte：**"嵌入客户现场识别高价值 GenAI 用例"**
- 国内某 AI 公司：**"连接市场与研发的神经末梢"**
- Palantir：从**需求定义 / 架构设计 / POC 到生产部署**，全过程驻场

## 2. 它在岗位坐标轴上的位置（最重要的一张图）

```
大模型算法工程师  ─►  大模型应用工程师  ─►  解决方案架构师  ─►  FDE
（最左·模型本身）    （左中·搭RAG/Agent）   （中间·让客户买单）  （最右·让模型在客户环境跑起来）
      ↑                    ↑                      ↑                ↑
   硕士/博士             ← 你现在在这 →          会做方案          驻场交付
   发论文                 缺服务化                 缺商业语言         缺客户沟通
```

**关键判断**：FDE 不是"另一个岗位"，它是你这条路往右走的**终点**。
现在投 FDE 是"够得着但会露怯"（缺驻场经验和客户沟通证据）。
正确策略：**用 8 个月从"左中"走到"右"，FDE 是目标不是起点。**

**唯一例外**：国内有 **1–3 年本科**的 FDE 岗位（共联通信·上海），说明门槛有下沿。
如果 30 天后你有了公网作品，可以**投一家试试拿反馈**，不为 offer。

## 5. OpenAI FDE 白皮书 · 三项能力（细读版）

### ① LLM 深度
- 不止调 API：理解 **tokenization / context windows / function calling / system prompts / rate limits / failure modes**
- 能在 **RAG / 微调 / 提示工程** 之间权衡
- 能用 **成本-延迟-质量** 论证选型
→ **你的缺口**：stage1 有成本记账，但从没用它做过一次"选型论证"。

### ② 全栈 + 基础设施
- Python / TypeScript 后端、React / Next 前端、Docker / K8s / 云
→ **你的缺口**：全部。

### ③ 客户沟通
- 把"我们想要 AI"转成**具体用例与里程碑**
- **能对不切实际的期望说不**
→ **你的缺口**：全部，而且**这一项没有任何课程能替代真实练习**。

## 7. 三个真相（写下来防幻觉）

1. **"不写代码年薪百万"是伪命题。** FDE 写的是：定制化集成、脚本、环境配置、排障。技术门槛低于算法岗，但不是没有。
2. **出差是硬指标。** Deloitte 明确 50%。上海某公司 JD 写"能接受长期驻场"。**这一条你得自己先有答案。**
3. **AI 经验是门槛，但不是全部。** 60% 权重在沟通与商业。

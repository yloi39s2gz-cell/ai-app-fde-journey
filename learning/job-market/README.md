# 岗位情报站（江浙沪 · AI 方向）

> 这个文件夹回答一个问题：**市场现在到底要什么，和我现在会的东西差多少。**
> 每 3 天自动轮巡一次，把新情报写进这里，再回写学习计划。

---

## 1. 为什么要有这一层

`learning/ai-app/` 和 `learning/fde/` 是**输入侧**（我要学什么）。
但学习计划最容易犯的错是：**闭门造车**——学了一堆面试官不问的东西。

所以加一层**输出侧的锚**：真实 JD 原文。每个月拿出来对一次，你会立刻发现：
- 哪些技能是 20 家 JD 里 18 家都要的（必修）
- 哪些是只有 1 家提的（选修，别花时间）
- 市场上冒出来的**新岗位**（比如这次的 FDE）——这些往往在门槛还没抬起来时最好进

## 3. 三个文件怎么用

| 文件 | 什么时候看 | 看什么 |
| --- | --- | --- |
| `INDEX.md` | 每次轮巡后 | 有新岗位吗？薪资动了吗？我的匹配度涨了没 |
| `能力差距总表.md` | 每两周 | 我的"必修项"还剩几条没补 |
| `positions/<岗位>/学习计划.md` | 每周一 | 本周该补哪条，怎么验收 |

## 4. 硬规矩

1. **JD 原文优先于我的总结**。每个要求项后面必须能追到来源链接，追不到就标注"网络摘要，未核原文"。
2. **不许把"某公司想要"写成"市场要"**。要写"X 家公司里的 Y 家提到"，数字要能数出来。
3. **差距要诚实**。写"❌ 缺失"比写"了解即可"有用得多。
4. **增量计划必须挂到已有 stage 上**。如果一条任务不属于任何 stage，说明它是新赛道，要单独开 stage（并且说清为什么值得开）。
5. **每轮轮巡必须落一份快照**。哪怕结论是"没变化"——那也是一个数据点。

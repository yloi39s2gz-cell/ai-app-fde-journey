# 轮巡 SOP —— 每 3 天怎么做（照着走，不靠记忆）

> 目标：**25 分钟内**完成一轮，产出 1 份快照 + 对学习计划的增量修改。
> 原则：**不追求全**，追求**能对比**。同一批查询词反复跑，才能看出趋势。

---

## 0. 前置检查（1 分钟）

- [ ] 今天是第几轮？上一轮快照在哪？（`radar/` 里最新的日期文件）
- [ ] 上一轮留下的 `TODO` / `待核` 有哪些？

---

## 1. 固定查询词（每轮都跑这 8 条，保证可比）

用 `advanced_search`，**engine 指定 `tavily`**（原因：bing 在中文招聘查询上返回大量无关结果，实测过）。

| # | 查询词 | 目的 |
| --- | --- | --- |
| Q1 | `苏州 AI 大模型 应用 工程师 招聘 薪资 2026` | 苏州主盘 |
| Q2 | `南京 AI 应用 大模型 工程师 招聘 薪资 2026` | 南京主盘 |
| Q3 | `FDE 前沿部署工程师 招聘 薪资 2026` | FDE 专项（增量最快的岗位） |

| Q5 | `Agent 开发工程师 招聘 薪资 要求 2026` | Agent 开发 |

---

## 2. 增量查询（发现新方向时才加，最多 2 条）

触发条件：上一轮或本轮在 Q1–Q8 的摘要里看到**没见过的岗位名**。
例：看到"世界模型产品经理"、"VLA 工程师"、"AI 训练数据工程师" → 加一条专项查询。

---

## 3. 记录格式（每条 JD 必须记满 6 项）

```
【公司/机构】机构名（可加城市）
【岗位名】JD 上写的原话，不要自己规范化
【薪资】原文数字（如 15-30K·13薪），没有就写"未标注"
【经验/学历】原文门槛
【要求原文摘录】3–5 条关键词级要求，尽量保留原话
【来源】URL
```

> 抓不到原文（403 / 反爬）时，写 `【来源】搜索引擎摘要，未核原文`。**不许把摘要当成原文引用。**

---

## 4. 落盘（5 分钟）

1. 新建 `radar/YYYY-MM-DD.md`，用下面的模板
2. 把新岗位/薪资变化 追加到 `INDEX.md`
3. 把新的要求项 追加到 `能力差距总表.md`（已存在的项只更新计数）
4. 如果某个岗位的要求变了 → 改它的 `positions/<岗位>/能力矩阵.md`

（按上面 6 项格式，逐条列）

## 5. 收尾（2 分钟）

```powershell
cd C:\Users\admin\Desktop\学习
git add -A
git commit -m "job-market: 第N轮轮巡快照 YYYY-MM-DD"
git push
```

> **没有 commit 的一轮等于没轮。**

## 6. 已知坑（每轮补充，别重复踩）

| 坑 | 现象 | 绕法 |
| --- | --- | --- |
| BOSS 直聘直连 | `zhipin.com` 返回 `{"code":37,"message":"您的环境存在异常."}` | 不抓原站，用搜索引擎摘要 + 第三方汇总站 |
| 知乎专栏 | web_fetch 返回 HTTP 403 | 只看搜索摘要 |
| 百度百科 | 403（百度安全验证） | 换 Bing 百科或其他源 |
| bing 引擎中文招聘查询 | 返回词典、游戏攻略等垃圾结果 | **首选 tavily** |
| 猎聘 | 部分页面可抓，部分需登录 | 优先抓列表页摘要 |

## P0 — 主攻（这两个决定你 8 个月的成败）

### 1. AI 应用工程师 / AI 应用开发

**它是什么**：把大模型能力变成公司业务里能跑、能上线的功能。不训模型，**用**模型——搭 RAG、设计 Agent、接业务系统、包成 API、部署上线、做效果评测。

**它为什么是你的主战场**：占所有 AI 岗位的 **60.97%**，招聘量最大的一层。

**谁在招（江浙沪）**：
- 苏州：同程旅行 15-30K·15薪（1-3年本科）、思迹信息【园区】15-30k·13薪、联滔电子【锦溪】18-25k、凯瑞斯德生化【吴江】8-15k、飞依诺【园区】15-22k·13薪
- 南京：中科南京 AI 创新研究院 20-30k·14薪、致网科技 13-18k·14薪、江苏江南生态碳 15-25k
- 门槛：**本科 1-3 年**，不需要更高学历

**和你什么关系**：✅ **这就是你该打的仗**。11 家 JD 里 Python 11/11、大模型四件套 11/11、FastAPI 9/11、Docker 8/11。
你缺的全是"外壳"（服务化 / 容器 / 云），内核（RAG + Agent + 评测）已经够了。

**详细**：[positions/ai-application-engineer/](positions/ai-application-engineer/README.md)

---

### 2. FDE / 前沿部署工程师

**它是什么**：把大模型塞进客户已有的、又脏又乱的系统里，并且让它真的产生业务结果。
JD 原话最能说明它是什么——Deloitte 写"**嵌入客户现场识别高价值 GenAI 用例**"，国内某 AI 公司写"**连接市场与研发的神经末梢**"。

**它为什么值得盯**：所有技术岗里**扩招最快**的一个，+1522.73% 居首。Indeed 上从 2025-04 的 **643 条**涨到 2026-04 的 **5,330 条**（三个独立来源印证）。

**谁在招**：Palantir（年薪 17-20 万美元起）、Deloitte、阿里云 35-55K×13薪、蚂蚁集团【杭州】、**南京 FDE 专家 35-65k·15薪**、上海青浦 20-45k·13薪、帆软软件【杭州】20-40k、共联通信【上海】**1-3 年本科**。

**能力模型（这条最重要）**：
| 技术能力 | 客户沟通 | 商业敏锐度 |
| --- | --- | --- |
| **40%** | **35%** | **25%** |
→ **60% 的权重不是技术。** 而你现在 100% 的时间都在补技术。

**和你什么关系**：⚠️ **不是现在投，是 8 个月后的目标**。
- 出差是硬指标：Deloitte 明确 **50%**，蚂蚁的岗位名直接写着"**出差面客驻场**" ← **这一条你得先自己回答**
- **苏州连续两轮没有具名 FDE JD**；江浙沪的实际战场是 **上海 → 杭州 → 南京**，没有苏州

**详细**：[positions/fde/](positions/fde/README.md)

## P1 — 并列替补（性价比高，且缺口能被主攻的计划顺带补掉）

### 3. Agent 开发工程师

**它是什么**：设计、实现、评测"能自己调工具完成任务"的 Agent——工具定义、循环控制、状态管理、多 Agent 协作、失败恢复。

**热度**：招聘指数 **393.93，断层第一**（第二名差得很远）。平均月薪 **69,834 元**。

**为什么它对你性价比最高**：你的 [stage4](../../learning/ai-app/stage4/) 手写的 Agent 循环**就是它的内核**。
缺口只有 LangGraph / 原生 tools / 多 Agent / 状态持久化——**这四项正好是我排在窗口一第 2 周（D8–D14）的任务**。

**新增要求项（10-08）**：ReAct / CoT 推理框架（你的循环本质就是 ReAct，只是没用这个名字）、AutoGen（**不学**，与 LangGraph 重叠）。

**详细**：[positions/agent-engineer/](positions/agent-engineer/README.md)

---

### 4. AI 测试 / 评测工程师

**它是什么**：给 AI 应用建一套"能不能用、用得对不对、花多少钱"的度量体系。
**注意它评的不是"答案对不对"，是"Agent 每一步做得对不对"**——工具调用、工具轨迹、权限、状态变化、资源消耗、产物。

**为什么我认为它最被低估**：招聘量第 2，但讨论度极低（岗位名不统一，搜"评测工程师"搜不全）→ **投的人少**。

**门槛（10-08 拿到 JD 原文）**：上海人工智能实验室要求 **本科 + 3 年**、Python/Java/Go 任一、JSON/YAML、Linux/Shell。
→ 比 FDE 友好，远低于 AI 产品经理。

**和你什么关系**：✅ 你的 stage2（注入测试）、stage3（评测集）、stage5（消融 + 指标）合起来**已经是它的雏形**。
缺口只有两条：**指标维度太窄**（只有对错）+ **没复现过开源 benchmark**。约 6-7 天能补齐。

**顺带的好处**：做这套评测的过程会同时产出 AI 应用工程师要的"效果评估体系"、FDE 要的"成本-延迟-质量论证"、AI PM 要的"成本效能平衡点"。**一鱼三吃。**

**详细**：[positions/ai-evaluation-engineer/](positions/ai-evaluation-engineer/README.md)

## P2 — 备选（先了解，不投入）

### 5. AI 解决方案 / 售前

**它是什么**：签单**之前**把"我们能做什么"讲成"你的问题能怎么解决"，并给出方案和报价。
FDE 是签单**之后**进现场交付。

**和 FDE 的关系**：同一个能力模型，技术权重更低（30%）、沟通更高（40%），**出差压力小得多**。
→ 如果你想走 FDE 路线但工程经验不够，**可以先用它当降级入口**。

**和你什么关系**：P2。本轮只有 1 条具体岗位（南京炫佳网络 AIGC 售前解决方案），证据不足，下一轮补。

**详细**：[positions/ai-solution-architect/](positions/ai-solution-architect/README.md)

---

### 6. AI 业务效能岗

**它是什么**：不开发 AI，而是**用** AI 在业务里拿结果——运营 / 销售 / HR / 市场 / 客服 / 内容岗位的"AI 加强版"。

**数据**：平均月薪 44,183 元，**供需比 2.45（三类里最卷）**。但 AI 能力带来的薪资溢价很实在：销售类 +27.80%、运营类 +20.30%。

**和你什么关系**：**兜底位**。它不要求 3 年工程经验，所以如果 8 个月后主战场没打好，这条路仍然开着。
唯一要投入的是 BE-1「AI 提效表」（记录一周用 AI 做了什么、没有 AI 要多久）——而这个也是所有岗位面试都会问的。

**详细**：[positions/ai-business-efficiency/](positions/ai-business-efficiency/README.md)

## P3 — 明确不碰（写下理由，防止每轮动摇）

| 岗位 | 热度数字 | 为什么不做 |
| --- | --- | --- |
| **大模型后训练 / 推理优化** | 预训练 80,801 元/月（全场最高）；底座岗供需比 0.78（唯一供不应求） | 需要**硕士+、GPU 集群、论文**。你本机没有 GPU，这个方向只能"读出来"不能"做出来"——而面试官要的是做出来。**唯一要懂的事**：什么时候该微调、什么时候该 RAG、什么时候只改 prompt（这个别的岗位也会问） |
| **具身智能 / VLA** | +283.91% / +365.70% | 需要机器人学、ROS、仿真、强化学习、真机硬件。**这是另一条独立的 8 个月的路** |
| **世界模型** | +644.80% | 门槛最高的一个。而且 **+644% 是"高增长低绝对量"**——基数没披露，可能是从 5 个涨到 37 个 |
| **多模态算法（图像生成 / 3D）** | 苏州放出岗位较多的方向之一 | 需要 CV 基础（三维重建 / 点云）。苏州那批 20-40K 的 AIGC 岗**都要硕士** |

> 苏州市场有个说法值得记住：**"2026 年苏州本地企业更倾向招有落地经验的人，纯研究背景的硕士如果没做过完整项目，面试通过率会打折扣。"**
> → **这条对你有利**（你有 stage0–5 六个完整阶段），但前提是它们有**可演示的形态**（公网 URL / 录屏 / 清晰的 README）。

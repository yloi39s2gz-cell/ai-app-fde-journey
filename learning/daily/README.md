# daily/ —— 每日学习卡的存档

## 机制（只有三条）

1. **`学习/今天学什么.md`（仓库根目录）永远是"今天"那一张。** 你每天只需要打开它。
2. **每天更新它之前，先把旧的那张复制到这里**，命名 `YYYY-MM-DD-Dnn.md`（日期 + 窗口第几天）。
3. **存档不改、不删、不回填。** 它是你真实进度的证据——包括"没做"的那些天。

## 为什么要有这个文件夹

因为**「今天学什么」会被覆盖，而「我实际上做了什么」不能丢**。

如果不存档，30 天后你只会看到一张最新的卡，完全想不起来：
- 哪几天跳过了日常 A（那说明手写能力没在涨）
- 哪几天卡在同一个坑上（那说明需要换讲法，不是你不努力）
- 哪几天任务量定得不合理（那说明要调计划，不是要硬扛）

打卡表 [../../每日打卡.md](../../每日打卡.md) 记的是**结果**（勾），这个文件夹存的是**当天到底要求你做什么**（过程）。
两张表对起来看，才知道计划哪里排错了。

## 命名规则

```
YYYY-MM-DD-Dnn.md
     │      └── 窗口一里的第几天（D1 = 2026-10-04）
     └── 日期
例：2026-10-08-D05.md
```

## 存档内容

和当天 `今天学什么.md` 一字不差地复制过来，**不要"整理干净"**。
它要保留当天的原貌——包括我写错的预估工时、当天才发现的技术坑。

> **注意**：`今天学什么.md` 在仓库根目录（`学习/` 下第一层），不在 `learning/` 里面。
> 因为它是你每天第一眼要看的东西，放在最深的地方等于藏起来。
